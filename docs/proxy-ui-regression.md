# 代理页样式与设备回归

日期：2026-10-19。

## 实现

- 代理页从标签切换改为可独立展开的圆角策略组。组头展示名称、当前节点和类型，展开后提供定位当前节点、整组测速及收起操作；滚动时组头吸顶。
- 顶部使用圆形搜索与更多按钮。搜索匹配组名、节点名或协议，不改变实际选择；更多菜单支持展开全部、收起全部。
- 常规字号下，640vp 以下单列分组，其余宽度双列分组，两列独立滚动。每组默认双列节点；内容过窄或系统字号较大时改为单列，组头操作按需换行。
- 节点采用浅灰圆角背景，名称最多两行，右上角蓝色圆形勾选标记，底部显示协议和延迟。未测速使用 SVG 闪电，测速中使用进度指示，失败显示“超时”。TCP/UDP 信息保留在节点的无障碍描述中。
- 保留 RuntimeStore 的运行时/预览选择、测速并发及错误处理。测速按钮的点击和按压反馈与节点选择分离，禁用测速按钮不会误选节点。
- 参考图中的订阅头像没有对应的现有数据字段，因此使用组名首字符作为占位，不引入图标下载或品牌资源。复用现有主题、PageHeader、导航和减少动画配置，没有新增依赖。

修改模块：ProxyPage、ProxyNodeCard、RuntimeUtils、ResponsiveUtils、浅深色主题资源、三个 SVG 图标、代理展示与延迟文案测试。

## 设备与测试方式

使用本机已有的 **Mate X6** 和 **Mate 90 Pro 模拟器**，HarmonyOS 7.0.0 / API 26，x86_64。

Go 核心只提供 ARM64 预编译库；本轮用临时构建替换代理页的 Store 导入，在实际 ProxyPage、ProxyNodeCard 和应用导航中注入隔离快照。覆盖正常延迟、超时、未测速、进行中、自动选择组、长名称、多个策略组及节点选择。未写入订阅数据库、未绕过核心能力检查，模拟延迟不代表真实网络测速。

正式构建前按字节恢复原导入并移出临时源码。最终 signed/unsigned HAP 的 `ets/modules.abc` 均检查不含 `ProxyQaFixture`。

| 验证场景 | 结果 |
|---|---|

| Mate X6 模拟折叠，1080×2440，约 346vp | 自动切换单列分组，展开状态和节点内容正常 |
| Mate X6 横屏，2440×2240，约 781vp | 双列分组，安全区域和底部滚动留白正常 |
