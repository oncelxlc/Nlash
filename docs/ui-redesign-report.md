# 全应用界面重设计与验证记录

日期：2026-10-03。

## 实现范围

- `Index`、`AppNavigationState` 和导航模型统一为概览、代理、配置、活动、设置五项入口。原 `AppPage` 枚举值保持不变，追加 `ACTIVITY`；旧请求/连接意图映射到活动页对应分段，通知继续进入概览。
- 新增 `ActivityPage`，分段之间分别保存连接搜索、请求搜索与请求状态筛选，仅挂载当前分段。一级导航保留上次选择的分段；离开活动页后搜索与筛选随页面卸载重置，延续现有按需挂载策略。
- 概览集中呈现配置、状态、运行时长、模式和启停操作。60 秒速度曲线采用上传蓝、下载青绿，累计流量改为数字；活动连接和当前配置可直接导航。Core 重启进入次级菜单并保留确认流程。
- 代理使用 1/2/3 列节点布局，节点选择与测速为独立按钮。配置区分当前使用和其他配置，保留更新、用量、到期、编辑、自动更新与删除；编辑器使用滚动表单及独立保存区。活动列表支持展开详情；设置按外观、网络、运行数据、数据管理和关于分组。
- 两套主题资源统一文字、表面、输入框、状态、按钮、弹层和图表颜色；新增本地 SVG 操作图标及 `PageHeader`、`StatusBadge`，复用空状态组件。导航 SVG 使用可被系统材质正确染色的填充图形。
- 系统字体，标题 28fp、主要数值 32fp、正文 16fp、辅助信息 13fp；主要操作至少 48vp，控件圆角 12vp，面板圆角 16vp。沿用 640/900vp 断点，边距 16/24/32vp；移除信息卡强制等高，保留曲线明确高度与底部导航避让。
- Canvas 从当前 UI 上下文读取主题资源，在配置、主题及尺寸变化后重绘，卸载时释放监听。应用声明跟随系统字体；入口支持遵循系统旋转锁定的横竖屏切换。

保留 HdsTabs 系统材质、握姿适配和按需挂载。未新增依赖，未修改存储格式、Go/C++ Core、VPN 协议、应用名称或启动图标；原有未提交的 `build-profile.json5` 和 `.agents/` 保持原状。

## 模拟器验收

使用现有 Mate 80 Pro 与 Mate X6 模拟器，HarmonyOS 6.1.1（API 24），均为 x86_64。本轮没有操作真机。

| 场景 | 结果 |
|---|---|
| 手机竖屏，1280×2832，约 366vp | 五项导航可用，概览纵向排列，浅色/深色文字、图标、曲线背景与控件配色正常 |
| 宽屏竖屏，2240×2440，约 717vp | 概览双栏，配置和设置布局正常，短内容从顶部开始 |
| 宽屏横屏，2440×2240，约 921vp | 双栏布局可用；系统“特大”字号下模式文字完整，活动分段和设置按钮可读 |
| 设置长页面 | 特大字号下可滚动到“关于”末项，末项底边 1815px，导航顶边 2004px，无遮挡 |
| 活动分段 | 两份搜索词和请求状态在分段切换时各自保留；离开后返回记住请求分段；UI 树仅保留一个 TabContent |
| 导航返回 | 设置返回概览，概览再次返回桌面；应用可重新进入 |
| 配置导入弹层 | 地址输入、键盘和校验失败反馈可用，失败后保留输入；未将失败导入保存为配置 |
| 深色冷启动与主题切换 | 导航图标正确染色，Canvas 网格使用对应主题资源 |

验收中修复了页面标题 Builder 回调的上下文绑定、短内容垂直居中、深色 Canvas 初始颜色、SVG 染色以及大字号模式文字截断问题。结束时已恢复模拟器标准字体、默认显示缩放、竖屏及应用“跟随系统”主题；临时导入测试服务和端口转发已关闭。
