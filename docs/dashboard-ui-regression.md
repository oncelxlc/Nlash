# 仪表盘样式与设备回归

日期：2026-10-19。

本文前半部分保留首轮实现记录；后续的固定排序、配置卡、内存卡和状态卡调整见文末各节。

## 实现

- 页面标题、底部导航、布局编辑提示与保存错误文案由“概览”统一改为“仪表盘”。内部导航枚举、通知目标与偏好存储键保持兼容。
- 参照提供的图片采用浅灰背景、大圆角白色卡片、蓝色主操作、浅灰内嵌区与轻阴影；深色使用独立语义色。
- 顶部状态卡整合公网 IPv4、地区、运行时长、当前配置和启停按钮。保留公网刷新、异常原因、Core 重启与代理繁忙时的禁用逻辑。
- 手机的网络速度卡包含上传／下载两个面板；展开屏为两个独立卡片。两条曲线分别使用各自的真实样本和峰值，保留累计量、缺失数据与绘图失败反馈。系统大字号时面板上下排列，避免单位被拆行。
- 出站模式改为横向选择；新增独立 VPN 开关、实际服务状态和策略组入口。配置卡展示更新时间、到期日及已知的订阅用量；实时连接、最近请求分别进入活动页对应标签。内存卡明确展示 Core 实时内存。
- 复用现有宽度断点，并考虑系统字号；卡片高度随内容增长。滚动区保留底部导航空间，图标按钮具有无障碍名称，状态包含文字。
- 保留拖动排序和前移／后移菜单。旧 `traffic` 合并到速度卡，旧 `duration` 合并到状态卡；已有顺序优先，缺失的新卡片追加，不删除偏好数据。
- 未新增依赖。新增三个 SVG，并修正为可随 ArkUI `fillColor` 着色的填充路径。

改动主要位于 `DashboardPage`、三个 Runtime 展示卡片、Dashboard 模型／常量／工具、Runtime 曲线工具、PreferenceRepository、浅深主题及文案资源，以及相关测试。

## 设备与验证方式

使用本机已有的 **Mate X6** 和 **Mate 90 Pro 模拟器**，HarmonyOS 7.0.0 / API 26、x86_64。

正式包在两台设备上检查了未配置／Core 不支持的真实状态。现有 Go 核心只有 ARM64 预编译库，因此运行中的流量、配置、策略组和开关反馈通过临时隔离快照验证：仅替换 DashboardPage 的 Store／服务导入，使用实际页面、组件、主题和应用导航，不写入订阅数据库、不启动系统 VPN。模拟流量不代表真实网络测量。

## 状态卡与 IP 质量

- 按新增参考图显示状态标签、国家代码四叶草、出口 IPv4、类型和质量标签、运行时长、组织，以及蓝色花形启停按钮。保留原来的 VPN 授权／启停条件和异常反馈；状态卡内的“当前配置”替换为组织，配置仍由下面的配置卡管理。
- 四叶草是刷新入口，宽屏和窄屏均显示国家／地区的两位 ISO 代码。点击立即进入加载态，保留代码并显示进度环，查询期间禁止重复点击；刷新 IP、组织、类型和质量。VPN 开启、关闭及实际节点切换后同样刷新。
- IPv4 通过 [ipify](https://www.ipify.org/) 获取，失败时使用原有 IP.SB 地址接口。再向 [IPQuery](https://ipquery.io/) 的 `https://api.ipquery.io/{ipv4}` 查询该地址的组织、地区和风险信息；无密钥、无新增依赖，所有请求使用 HTTPS。字段依据其 [官方文档](https://ipquery.gitbook.io/ipquery-docs)，实现前已用实际接口核对返回结构。
- IPQuery 的风险分为 0–100，越高风险越高。应用分级规则：0–19“优”、20–59“普通”、60–100“较差”；机房或已知 VPN 至少为“普通”，Tor／公开代理为“较差”。这是一项风险参考分级，不是网速测量、网站解锁能力或安全保证。风险分和必要标记缺失、越界或格式错误时显示“未知”。
- 类型按实际标记显示“机房”“移动”“非机房”，无法确定则“类型未知”。API 未提供住宅／商业的可靠分类，因此不把“非机房”擅自标为“住宅”。组织优先使用 IPQuery `isp.org`，其次 `isp.isp`。
- 质量服务不可用时降级使用现有 IP.SB 地理信息和组织，保留已经取得的新 IP；质量仍为未知并显示重试提示。两个信息服务都失败时也保留有效 IP。响应 IP 必须与当前探测地址一致，拒绝非十进制 IPv4 和混合地址信息。网络／节点变化立即使在途结果失效，不发布旧出口结果。

单元测试 entry 99/99、proxy_core 1/1 通过，新增风险等级边界、代理标记、缺失／无效风险字段、地址校验、数据源降级和新 IP 保留测试。

## Header 渐隐与状态背景贴边补验

- `FadingScrollLayout` 为仪表盘、代理、配置列表／编辑器、设置和活动列表的固定操作区提供统一渐变。正文上滑进入标题下方后消隐，标题及操作按钮保持可用；透明端保留对应主题的 RGB，浅色不会出现灰带。
- 顶部留白由实际 header 高度双向同步。首次测量完成后再创建滚动内容，确保 List 首项不被遮住；代理分组吸顶、选中节点定位、搜索区展开和活动页返回仍正常。
- 状态背景采用参考图的大花瓣轮廓及深色蓝灰色，SVG 使用无等比留白的缩放方式；背景与正文放在同一个 Stack 中，按正文实测高度铺满，消除宽屏上下直线边带，并随运行／停止状态切色。

Mate X6 与 Mate 90 Pro 模拟器均通过配置列表／编辑器、实时连接和请求记录的首项留白、固定操作区与滚动断言。两台的浅色／深色仪表盘与设置页完成截图检查；状态背景的顶边像素和启停切色通过检查。Mate X6 的 2240×2440 展开、1080×2440 折叠尺寸及 2440×2240 横屏通过 header／卡片／按钮边界断言；Mate 90 Pro 最大字号下 header、IP、组织和状态按钮均可见。代理页重新进入后仍定位到已选节点。
