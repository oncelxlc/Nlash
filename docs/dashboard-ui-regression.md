# 仪表盘样式与设备回归

日期：2026-10-19。

## 实现

- 页面标题、底部导航、布局编辑提示与保存错误文案由“概览”统一改为“仪表盘”。内部导航枚举、通知目标与偏好存储键保持兼容。
- 参照提供的图片采用浅灰背景、大圆角白色卡片、蓝色主操作、浅灰内嵌区与轻阴影；深色使用独立语义色。
- 顶部状态卡整合公网 IPv4、地区、运行时长、当前配置和启停按钮。保留公网刷新、异常原因、Core 重启与代理繁忙时的禁用逻辑。
- 手机的网络速度卡包含上传／下载两个面板；展开屏为两个独立卡片。两条曲线分别使用各自的真实样本和峰值，保留累计量、缺失数据与绘图失败反馈。系统大字号时面板上下排列，避免单位被拆行。
- 出站模式改为横向选择；新增独立 VPN 开关、实际服务状态和策略组入口。配置卡展示更新时间、到期日及已知的订阅用量；实时连接、最近请求分别进入活动页对应标签。内存卡明确展示 Core 实时内存。
- 复用现有宽度断点，并考虑系统字号；卡片高度随内容增长。滚动区保留底部导航空间，图标按钮具有无障碍名称，状态包含文字。
- 保留拖动排序和前移／后移菜单。旧 `traffic` 合并到速度卡，旧 `duration` 合并到状态卡；已有顺序优先，缺失的新卡片追加，不删除偏好数据。
- 未新增依赖。新增三个 SVG，并修正为可随 ArkUI `fillColor` 着色的填充路径。

改动主要位于 `DashboardPage`、三个 Runtime 展示卡片、Dashboard 模型／常量／工具、Runtime 曲线工具、PreferenceRepository、浅深主题及文案资源，以及相关测试。

## 参考图与现有能力的对应

本轮为界面调整，所有正式数据继续来自现有 Store 与服务。图中的 IP 住宅／机房分类和质量评分、内网 IP／局域网代理、第三方网站可用性探测、DNS 查询总数、应用进程内存尚无对应接口，本轮未新增这些后台能力，也没有以固定数值代替。

服务状态展示真实的 Core、VPN、配置及公网查询状态；内存只展示已有的 Core 数值；策略组使用组名首字符，没有引入外部头像或品牌图片。

## 设备与验证方式

使用本机已有的 **Mate X6** 和 **Mate 90 Pro 模拟器**，HarmonyOS 7.0.0 / API 26、x86_64。

正式包在两台设备上检查了未配置／Core 不支持的真实状态。现有 Go 核心只有 ARM64 预编译库，因此运行中的流量、配置、策略组和开关反馈通过临时隔离快照验证：仅替换 DashboardPage 的 Store／服务导入，使用实际页面、组件、主题和应用导航，不写入订阅数据库、不启动系统 VPN。模拟流量不代表真实网络测量。

每次临时构建都按字节恢复正式页面并移除临时源码；最终 signed／unsigned HAP 的 `ets/modules.abc` 均检查不含 `DashboardQaFixture`、`DashboardQaRuntime` 或示例 IP。
