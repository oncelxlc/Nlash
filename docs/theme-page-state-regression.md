## 连续切换色彩与动画的频闪修复

同日真机追加回归发现：每次保存外观设置，`ThemePage` 都用 `saving` 禁用整页控件，触发按钮的禁用透明度；主题快照又可能把这帧保留到淡入过程。原版连续切换时，红色色块的截图像素从 `(244,66,54)` 变成 `(251,178,172)`，同时动画选项、文本缩放按钮明显褪色。

- 仅调整 `ThemePage`：保存锁保留在事件处理层，不再改变控件的启用外观；保存开始时不重复替换设置状态，重复点击已选项不再提交。原有保存失败提示和并发保存保护继续保留。
- 使用相同设备交替点击蓝色、紫色、滑动、淡入，共 40 次。修复版同步采集 60 帧，未操作的红、黄、灰色块各通道像素跨度均为 0，通过自动断言；最终选中项及控件启用状态正确，无快照捕获或释放错误。测试后保留测试前的紫色与淡入选项。
