# 代理会话数据清理回归

日期：2026-10-22。

## 行为

- 设置页移除“数据管理”及相关流量重置入口。
- 请求、实时连接、DNS 查询和流量曲线只在代理开启时记录、展示。关闭代理、Core 停止或失败时清空；后台页面也释放自己的记录副本。
- 关闭时停止 DNS 记录、关闭活动连接、重置内核流量计数；Core 继续提供配置和测速功能。
- 开关代理会使旧异步响应失效，避免上一会话的数据回填。仪表盘流量与运行时长在关闭后归零。
- 运行记录仅保存在内存中。强制关闭订阅中的 `profile.store-fake-ip`，启动 Core 时清理旧版本缓存数据库中的 IPv4/IPv6 Fake-IP 映射。
- 此处“代理数据”指运行记录；订阅配置、节点选择、常规设置及规则资源继续保留。
