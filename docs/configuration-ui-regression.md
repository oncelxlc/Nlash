# 配置页样式与设备回归

日期：2026-10-19。

## 实现

- 配置页沿用现有 PageHeader、主题资源和 ProfileStore，顶部改为添加/刷新胶囊与独立管理按钮，点击区域均为 48vp。
- 卡片采用统一大圆角背景，名称旁显示本地时区的 `YYYY-MM-DD` 到期标签，下方显示流量，右侧显示更新时间和蓝色圆形选中标记。流量最多保留一位小数，例如 `71.9GB / 150GB`。
- 640vp 以下单列，其余宽度双列。长名称最多两行，必要时省略；日期标签换行，卡片随内容增高，完整名称可在编辑页查看。
- 右上角三横线解释为“管理配置与排序”开关，进入后显示各卡片的更多菜单，沿用编辑、更新、上移、下移、删除及拖动排序。没有新增排序策略或修改持久化结构。
- 未提供流量时显示订阅主机或“本地 YAML”，未提供有效到期日时不显示日期标签。

修改范围：ConfigurationPage、ProfileUtils、ResponsiveConstants、两套主题中的日期文字颜色、两个 SVG 图标和 ProfileFeatures 单测。未新增依赖。

## 验证

使用本机已有的 **Mate X6** 和 **Mate 90 Pro 模拟器**，HarmonyOS 7.0.0 / API 26、x86_64。两台原先均未安装 Nlash。本轮通过测试运行器向页面实际使用的数据库写入隔离示例元数据，安装并运行真实页面；没有绕过订阅校验或伪造 Core 能力。

| 场景 | 结果 |
|---|---|
| Mate X6 展开，2240×2440，约 717vp | 双列卡片，标题、日期、用量、更新时间完整，选中态正确 |
| Mate X6 折叠，1080×2440，约 346vp | 自动切换单列，内容与底部导航无重叠 |
| Mate X6 横屏，2440×2240，约 781vp | 保持双列，内容在安全区域内 |
| Mate 90 Pro 竖屏，1280×2832，约 366vp | 单列卡片，顶部按钮与参考图结构一致 |
| 两台浅色/深色 | 卡片、图标、日期标签和选中态可读；日期文字对比度分别 5.49:1 / 6.68:1 |
| Mate 90 Pro 系统“特大”字号 | 长名称两行省略，日期完整，卡片自动增高；本地配置缺失订阅字段时正常显示 |
| 管理交互 | 菜单五项均可见；下移后顺序正确且选中项保持；编辑入口可打开原有表单 |
| 自动验证 | entry 87/87、proxy_core 1/1；新增日期格式、流量小数、双列边界断言；UI 树检查列数、控件尺寸与状态通过 |

结束时清理了本轮新安装应用的测试数据、卸载临时测试模块，并移出临时测试运行器源码。Mate 90 Pro 字体恢复“标准”、显示缩放保持“默认”，Mate X6 恢复展开竖屏；应用恢复空配置与跟随系统主题。
